Frequently Asked

Everything you need to know.

Is Leon safe to use?

Yes. Leon is a userscript that runs entirely in your browser. It only clicks visible "Skip Ad" buttons. The code is open and readable. No data leaves your device.

Will YouTube ban my account?

Leon only automates clicks on UI elements already present and clickable. It doesn't modify YouTube's code or block requests. Risk is extremely low, but use at your own discretion.

Does it work on mobile?

Leon works on desktop browsers with Tampermonkey. Mobile browsers don't support userscripts natively.

How do I update Leon?

Leon checks for updates automatically via Tampermonkey. Click "Check for userscript updates" in the Tampermonkey menu to get the latest version.

Is Leon really free?

Yes. Leon is free and open source. No ads, no premium tiers, no data collection. Share it with a friend if you find it useful.
